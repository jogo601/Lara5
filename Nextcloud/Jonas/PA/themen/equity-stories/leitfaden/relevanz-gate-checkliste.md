# Relevanz-Gate — Investmentargument

Operationalisierung des **Selection Criterion** aus dem Coding Guide.  
Entscheidung **vor** Kategoriezuweisung.

## Include

Selbstständige Aussage, die die **Investment-Attraktivität** begründet oder untermauert, insbesondere:

- Value Driver
- Wettbewerbsvorteil / Differenzierung
- Strategische Fähigkeiten
- Erwartete Investment Outcomes (Ziele, Guidance, Returns)

Form: Satz, Bullet, Caption, Heading+Caption.

**Test:** Entfernen der Unit entfernt genau ein Investment-Argument.

## Exclude (+ Log)

- Kontakt, Legal, Disclaimer
- Rein organisational (Nav, Trenner, Danke-Folie)
- Kein Bezug zur Investment Story
- Rein visuelle Grafik ohne Text
- Bloße Kennzahl **ohne** interpretierenden Claim  
  (Kennzahl + Claim wie „strong“, „leading“, „solid“ → Include)

## Borderline

Trotzdem Include/Exclude entscheiden, dann:

- `Uncertainty / Review Flag = 1`
- 1-Zeilen-Begründung in `Free-Text Note`
- Eintrag im Exclusion-/Borderline-Log bzw. Review-Pack

## Multiple Coding

Max. ca. **2** Subkategorien pro Unit; sonst Unit splitten.
